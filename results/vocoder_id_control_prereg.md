# 音高族空对照（相位声码器恒等臂）：预注册

**写于 2026-10-06，跑数之前。** 回应 voice-theory #4661 §三。

## 问题
librosa `pitch_shift` 内部是**相位声码器**（time-stretch + resample）。相位声码器本身就是一种声码器，
可能给真实语音引入类声码器伪影 → 真实分下移；伪造语音本就有伪影、无新增信息。
**这条路径能产生与「抹掉真实证据」完全相同的观测，但机制不同**——所以音高族的反转在排除这条之前不能记到"音高"头上。

## 空对照设计
- **恒等臂 `vocoder-id`**：`att_pitch(semitones=0)` —— 同一个相位声码器、不改音高，
  即 time-stretch(rate=1) + resample(identity) + fix_length 的完整往返。
  （**已实测确认**：librosa 对 rate=1 / n_steps=0 **不做短路**——输出与源逐位不同，
  逐点差 max=1.27e-4、mean=1.0e-5，即走过了完整相位声码器。）
- 源 = LA-P4 同一批 200 真实 + 598 伪造；真实与伪造**都过**同一变换（与其余族一致）。
- 评估：两后端（AASIST / AASIST-L），同族口径 AUC + 与 §2.2 同格式的**双侧位移表**。

## 判据（先写死）

以**官方 AASIST、同族口径、相对 la_p4_clean 干净真实分数中位**计：

- **V1（判负）**：恒等臂**真实分中位下移 ≤ −2** **或** 同族 AUC < 0.5
  ⇒ 相位声码器本身即可造成反转 ⇒ **音高族反转降级为"声码器伪影混淆"**，
  从机制证据中撤下（正文改为：无法把音高效应与声码器伪影分开），§2.6 标注撤回。
- **V2（判正）**：恒等臂 |真实分中位下移| < 1 **且** 同族 AUC > 0.9
  ⇒ 相位声码器中性 ⇒ 音高族反转**保留**为音高效应证据。
- **V2'（中间带）**：1 ≤ |下移| < 2 或 AUC 在 [0.9, 1.0) 与 <0.5 之间不适用——
  落此带则判"部分混淆"，音高结论降级为"方向性证据、量级不可全归音高"。
- **V3（位移表必报）**：音高四族（±2/±4）+ 恒等臂 + 时长匹配对照（reverb/speed）各一行，
  给真实位移、伪造位移、AUC（与 §2.2 表同格式）。
- **V4（附注）**：方向不对称——实测音高**下移**反转（0.166–0.267）比**上移**（0.215–0.367）更重。
  若 V2 成立，该不对称作为"非声码器伪影"的辅助观察（伪影机制不应产生如此强的不对称）写进附注，不作独立判据。
