## 实验 C：签号翻转规则（裁定 2.3「更便宜的一条」）

### 规则（实现前写死）

部署假设：**一个批次 = 一个信道**（同一次后处理链），因此不需要条件分类器做路由。
校准半边（说话人分半，33/33）标签已知（这是合法的校准集，非测试集泄漏）。

对每族 f：
```
m_r = median(校准半边 该族真实 分数)
m_f = median(校准半边 该族伪造 分数)
fire = (m_r < m_f)          # 触发则对评估半边该族分数整体翻号 s -> -s
```

### 判据（先写死）

- **R1 传输性**：触发集合 == 评估半边 AUC<0.5 的族集合（两个后端 × {p4fix, p4r} 四张表各自核）。
  允许 0 处不符；出现不符如实报为「规则失效」。
- **R2 上限（诚实边界）**：所有触发族的**翻号后** AUC ≤ 0.80。
  （即：翻号修的是"符号"，不是"能力"；若某族翻号后 AUC>0.80，说明该族其实没坏，须单独检讨。）
- **R3 误触发**：AUC>0.99 的编解码族触发数 = 0。

### 报什么

逐族：m_r、m_f、是否触发、评估半边 AUC 翻号前/后、传输性核对。
两个后端（AASIST / AASIST-L）并列。

## 实验 D：批内真实比例敏感性（裁定 2.1）

### 协议（实现前写死）

对象：**无监督中位数对齐**（报告 §6.1(b) 候选，是「免信道标签」里最便宜的一条；
与 §2.3 oracle 版不同——oracle 版用的是带标签的校准半边真实分数中位）。

每族、每个比例 p ∈ {50%, 30%, 10%}：
1. 批次 n=200 条，组成 = p·n 真实 + (1-p)·n 伪造，从**评估半边**抽（无放回）。
2. 干净参考 = `la_p4_clean` 同组成抽 200 条（独立 npz，与后处理批无关）。
3. 平移估计 `shift = median(批分数) − median(干净参考分数)`；`thr_cal = T_LA + shift`（T_LA = −1.093850）。
4. 指标 = 评估半边**该族全部真实**（n≈100，不重复计）在 thr_cal 下的 FPR。
5. 每 (族, p) 重复 **200 次抽样**（fixed seed = 20261005），报中位与 [2.5, 97.5] 分位。
6. 宏平均 = 跨 9 族取平均（先逐族对 200 次取中位，再跨族平均）。

### 判据（先写死）

- **H7a**：p=50% 时宏平均 FPR ≤ 0.10
- **H7b**：p=30% 时宏平均 FPR ≤ 0.10
- **H7c**：p=10% 时宏平均 FPR > 0.10（预测失败——中位数被伪造主导，平移估计被稀释）
- **H7d 单调性**：中位 FPR 满足 FPR(50) ≤ FPR(30) ≤ FPR(10)（不满足则报违反，不修判据）

参照值（已知，不属判据）：未校正宏平均 FPR = 0.413（冻结阈值）；oracle 版 §2.3 = 0.003。

### 诚实边界（预挂）

- 该规则**只对 FPR 负责**；对反转族（reverb/speed）FNR 不会被此规则修复——反转是排序问题。
- 真实比例 p 在部署时是"假设"，不是测量；本实验测的是**假设正确时**的敏感性，
  假设错配（如假设 50% 实际 10%）单列为附报。
