# GMM 第三后端（LFCC-GMM）：预注册

**写于 2026-10-06，跑数之前。** 依 voice-theory #4661 §四（RawNet2 弃用后的替代第三后端）。

## 为什么是 GMM
原始方案要的是"第三个**后端**"，不是第三个神经网络。LFCC-GMM 是 ASVspoof2019 官方基线：
特征=倒谱（LFCC+Δ+ΔΔ），分类器=**生成式**（两个 GMM），与两个端到端网络（AASIST/AASIST-L）不同源。

## 实现口径（写死）
- 特征：20 维 LFCC（c0..c19，STFT→20 线性三角滤波→log→DCT-II）；窗 25ms / 移 10ms；16kHz；
  ⚠️ 实现注记（2026-10-07）：torchaudio 2.11 已移除 `kaldi.lfcc`，故**手工实现**同一算法口径；
  **逐条 CMVN**（均值方差归一，官方基线做法）；拼接 Δ+ΔΔ（一阶/二阶差分，窗 2）⇒ 60 维/帧。
- VAD：能量门（保留帧能量 ≥ 该条中位 − 30 dB 的帧）；若 <20 帧则整条保留。
- 模型：**两条 GMM**（真实 / 伪造），各 **256 混合、对角协方差**（官方基线是 512 全协方差；
  这里为可复算与 CPU 成本降档，**降档本身作为实现差异声明**）。
- 训练数据：LA **train** 全部（25,380，A01–A06）；帧子采样：每条最多 200 帧（均匀取）。
- 分数：LLK(真实) − LLK(伪造)（逐帧平均）。
- 评估：LA eval 全量 71,237（**已知答案**）；LA-P4 各族（同族口径）；音高/vocid 族。

## 已知答案（跑前登记）
官方 ASVspoof2019 LA 基线文档：**LFCC-GMM eval EER = 8.09%，min-tDCF = 0.2116**
（dev EER 2.71%）。**2026-10-07 网络核实**：多篇第三方文献与官方基线实现一致引用该数
（来源含 ar5iv 2008.03464、UG Granada 论文、INRS 学位论文等；理论侧要求以官方文档为准，不用记忆值）。
本实现因 GMM 降档（256 对角 vs 官方 512 全协方差），**允许落在 8–14% 区间**；
超出 [6%, 18%] 判"实现有误"，先修再进表。

## 判据（先写死；防"弱检测器的 AUC≈0.5 被当成反转"，理论侧原话）

- **G1 判别力门槛**：编解码族（mp3-64k / aac-128k / opus-32k）同族 **AUC ≥ 0.95**
  **且** LA eval 全量 EER ≤ 18%（已知答案带）。**不过 G1 则本后端不得用于任何反转结论**
  （一个坏掉的检测器给 0.5 不算反转）。
- **G2 反转判定**（仅在 G1 通过后）：反转族（reverb-rt60-0.4 / speed0.9 / 音高）同族 AUC < 0.5
  **且** 说话人分层 bootstrap 95% CI 上界 < 0.5 ⇒ 记"第三后端复现反转"；
  若点估计 <0.5 但 CI 跨界 ⇒ 记"方向一致、单格不稳健"。
- **G3 三后端并表**：AASIST / AASIST-L / LFCC-GMM 三列并排报同族 AUC + CI；
  三后端一致才写"反转与架构族无关"。
