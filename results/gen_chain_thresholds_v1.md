# 生成链检查：阈值与逐族判据冻结 v1（2026-10-06）

依 voice-theory #4661 §六：**在跑其余族之前冻结**。此后任何改动须升版本号并在报告标注（post-hoc）。

## 冻结的阈值（含首轮跑完后已记录的 post-hoc 修订，现一并冻结）

| 指标 | 阈值 | 口径 |
|---|---|---|
| ΔRMS | ≤ 1.0 dB | 逐对 |
| Δdur | ≤ max(2%·len_src, 4296 样本) | 逐对 |
| clip_ratio(合成) | ≤ 1e-4 且 ≤ 源 | 逐对 |
| \|Δvoiced\| | ≤ 0.05（编解码族豁免，只报数） | 逐对 |
| \|Δf0\| 中位 | ≤ 0.02 | **成对交集门控帧** + 八度错误剔除 |
| \|Δlin\| | ≤ 0.05 | 族级中位（逐对散布 = yin 抖动噪声底） |
| \|Δtilt\| | ≤ 3.0 dB/kHz（编解码族豁免） | 逐对 |

**判定口径**：族级中位为主判据；逐对过阈率作次要报数。豁免项必须在报告里注明"豁免+理由"。

## 逐族期望表（**跑之前写死**；"设计期望"来自各攻击的构造，不是事后解释）

| 族 | Δdur 期望 | Δf0 期望 | Δtilt 期望 | 说明 |
|---|---|---|---|---|
| mp3-64k / aac-128k / opus-32k | 0 | 0 | 可大（削高频→豁免） | 负对照（已跑通，族级全过） |
| g711-8k | 0 | 0 | 大（8kHz 往返切高频） | **正对照 A**（tilt 必须被检出） |
| bandpass-300-3400 | 0 | 0 | 大（带通边沿） | 正对照 A 之二 |
| awgn-snr5 / snr10 | 0 | 0 | ~0（噪声抬底） | 应全过 |
| reverb-rt60-0.4 | 0 | 0 | 小 | 应全过 |
| **speed0.9** | **≈ +11.1%（×1/0.9）** | ≈ 0（time-stretch 保音高） | 小 | **正对照 B：dur 必须被检出为超阈** |
| 音高四族 ±2/±4 | 0（逐点相同） | **= 2^(±n/12)−1（±2 半音 ±12.2%、±4 半音 ±26.0%）** | 小 | **正对照 C：f0 必须被检出为设计值** |
| vocoder-id | 0 | 0 | 小 | 空对照（另见 vocoder_id 预注册） |

**正对照通过标准**：正对照族的对应指标**必须**超阈且量级与设计值一致（±30% 相对），
否则判"检查器对该类变化不敏感"，其余族的"通过"不能算数（理论侧 §六 的要求）。
