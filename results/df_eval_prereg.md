## 三条口径与聚合规则（条件二/三，跑前钉死）

| 代号 | 口径 | 说明 |
|---|---|---|
| **②全长-整条**（主） | 每文件按**原生长度**整条前向，不截不拼 | 无聚合选择，与 DF 任务定义（全长）一致；进正式表 |
| **①定长**（诊断） | 现有 LA 管线：np.tile 到 64600 | 与既有全部结果口径一致；只做内部对照 |
| **②b全长-滑窗**（稳健性） | 64600 窗、hop 32300，分数取**均值** | 仅作稳健性附列；聚合方式选择在跑前固定为"均值"，不试其他 |

- **②b 尾窗约定（跑前钉死）**：窗起点 0, 32300, … 铺到最后一个完整窗；末端若仍有未覆盖剩余，
  补一窗**锚定在文件末尾**（保证全长被覆盖）。<64600 的文件走 ① 的单窗 tile（=定长口径）。
  每条的窗数记录在 npz 的 `n_windows` 字段，可核。

- **聚合规则的阈值声明（条件三后半）**：DF 块只报 **EER / AUC（均阈值无关）**，
  不报任何"冻结阈值"类指标 ⇒ 聚合方式不影响工作点定义；滑窗均值只用于与②比 EER/AUC 的稳健性。
  （LA dev 冻结阈值 −1.093850 不用于 DF 块——跨语料阈值本就无意义，特此声明。）
- **报告格式（条件二）**：DF 数**单独分块**，不与 LA 行同列比较；①②两列并列，
  **差值本身作为一条结果**（处理方式同 §2.2b 同族/混合口径并列、§2 固定/随机参数并列）。

## 判据（先写死）

- **D1**：主列（②）与诊断列（①）的 EER 差 ≥ 1.0pp ⇒ 判定"定长口径对 DF 有实质偏差"，①不可作为 DF 的正式数
  （预期成立：22.3% 被截断，方向未定，双向都可能）。
- **D2**：② 与 ②b（滑窗均值）EER 差 < 0.5pp ⇒ 判"整条前向对聚合方式不敏感"，②可放心作主列。
- **D3**：DF 块首报必须带已知答案或明确声明"无锚"。当前**无 DF 锚**（文献数多为全长+官方 ASV 打分协议，
  与本子集不完全同构）⇒ 表注写"无外部锚，仅作轨内比较"，不得暗示与文献数等同。
- 反例条款：若 ② 出现 EER > 50%（反转），先查文件长度处理（是否漏了超长文件的显存截断），
  再查 ②b，两口径一致才允许写"DF 上亦反转"。
