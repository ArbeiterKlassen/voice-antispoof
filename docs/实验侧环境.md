# 实验侧环境（机器相关，2026-10-07 实测）

本文记录**本机特定**的环境事实，供协作者理解复算环境差异。仓库其他部分不含机器路径。

## 路径与运行

- 工作区：`/data1/cuitianxu/voice_ws`。**脚本不再硬编码该路径**：
  - Python：`WS = os.environ.get("VOICE_WS") or <脚本所在目录的上一级>`（自动探测）
  - Shell：`WS="${VOICE_WS:-$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)}"`
  - 解释器：`PY="${VOICE_PY:-python3}"`；本机覆盖写在 **`scripts/env.local.sh`**（不入库）
- 检测器侧解释器：conda env `ml2026_exp`（Python 3.10，torch 2.11.0+cu130，torchaudio 2.11）

## 运维纪律（踩过的坑，与 `docs/协作约定.md` 呼应）

- 大文件下载必须**可续传**（`curl -C -` + 重试）并做**内容级**校验（parquet 读 footer / 权重能 load），
  只查"文件非空"会被静默截断骗过（DF 分片与第三方 RawNet2 权重各中过一次）。
- 训练/评估脚本先 CPU 冒烟再上 GPU；冒烟用截断 manifest，产出落到独立目录。
- 共享机上长任务：`nice` 降优先级，线程数封顶（`OMP_NUM_THREADS`），避免把磁盘/CPU 打满。
