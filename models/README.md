# models

预训练权重与检查点不入库。本目录用下载脚本与校验和复现。

## 需要的外部权重

| 模型 | 用途 | 来源与状态 |
|------|------|-----------|
| AASIST | 主检测器 | 官方发布，LA eval 已知答案 0.83% |
| AASIST-L | 第二后端 | 官方发布，LA eval 已知答案 0.99% |
| RawNet2 | 第三后端 | 第三方权重，无公开源码，重建未过已知答案门槛，已弃用 |
| CosyVoice2 | 克隆生成 | 官方发布，环境待重建 |
| F5-TTS / XTTS-v2 | 跨模型对照 | 官方发布 |

## 准入规则

任何权重进结果表之前先过已知答案对拍。第三方权重若无公开源码，重建后在 subset 上对拍自报指标，
不过门槛就不入表、不进结论，重建代码与失败点存档备查。

RawNet2 是这条规则的实际案例。键名对齐到 0/0、正弦前端参数由缓冲值反推，但 subset 上
AUC 只有 0.655，而自报全量 EER 15.09% 对应约 0.93，差异到量级，判定重建不忠于原实现，弃用。
